# PaperAgent 最终回答质量真实 A/B 报告

测试日期：2026-08-23  
模型：`qwen3.7-max-2026-05-17`  
数据集：冻结的 `answer_quality_ab_v1`，16 个研究问题  
最终对照样本：Baseline 16 次 + PaperAgent 16 次；另对 1 次 Provider Failure 进行定向重跑，因此实际发起 33 次请求  
最终 Provider Failure：0

## 1. 测试要回答的问题

此前测试已经证明意图、路由、规划、工具和工作流能够正确运行，但不能直接回答：

> 增加 Research Planning、Evidence 约束和 Verification 后，最终研究回答是否真的比“把检索材料直接交给模型”更好？

本轮固定相同问题、模型和证据，只改变生成策略：

```text
Baseline
= 冻结论文材料 → 通用“根据材料回答”Prompt → 模型回答

PaperAgent
= 相同冻结材料 → Evidence Store → Research Writer 约束
→ Citation Validator → Claim-Evidence Validator → Answer Verifier
```

因此它主要测量回答组织、证据使用和不足披露的收益，不把检索召回差异混入结果。

## 2. 数据集与人工标注

16 题平均分成四类：

| 类别 | 数量 | 作用 |
|---|---:|---|
| 方法比较 | 4 | 检查比较维度、双方事实和边界 |
| 单篇总结 | 4 | 检查问题、方法、贡献和证据局限 |
| 多论文综合 | 4 | 检查跨论文脉络、综合判断和研究空白 |
| 证据不足 | 4 | 检查缺性能数字、成本、图像或最新来源时是否拒绝补猜 |

每题人工冻结：

- 必须覆盖的研究维度及关键词；
- 必须出现的关键事实；
- 每个事实允许支持它的 Evidence ID；
- 必须披露的证据不足主题；
- 明确禁止出现的无依据断言。

该标注保存在 `eval_harness/datasets/answer_quality_ab_v1.json`，评分后不根据模型答案修改。评分为基于人工标注的确定性代理指标，不冒充大规模用户盲评或主观满意度调查。

## 3. 指标口径

| 指标 | 计算方式 | 说明 |
|---|---|---|
| 回答内容质量分 | 维度覆盖×45% + 关键事实覆盖×35% + 安全边界×20% | 不含引用分，用于公平比较内容质量 |
| 研究维度覆盖率 | 命中的人工必要维度 ÷ 全部必要维度 | 回答是否完整 |
| 关键事实覆盖率 | 命中的人工关键事实 ÷ 全部关键事实 | 是否回答核心内容 |
| 声明证据支持率 | 关键事实所在语句就近引用允许 Evidence ID 的比例 | 声明是否可由指定材料支持 |
| 引用准确率 | 引用中真实存在于当前 Evidence Store 的比例 | 是否创造 Evidence ID |
| 证据可追溯率 | 被回答实际引用的证据 ÷ 当前可用证据 | 用户能否追到来源 |
| 不足披露率 | 需要披露不足的题中正确披露的比例 | 是否会在缺证据时强答 |
| 综合证据质量分 | 内容、支持、引用、追溯和边界的加权分 | 观察完整证据型回答，不单独作为内容提升口径 |

Baseline Prompt 没有要求 Evidence ID，所以其引用和可追溯率为 0 是实验设计结果，不能据此声称“内容质量提升 100%”。简历使用不含引用项的“回答内容质量分”，引用指标作为独立工程收益。

## 4. 最终真实结果

| 指标 | 直接生成 Baseline | PaperAgent | 变化 |
|---|---:|---:|---:|
| 回答内容质量分 | 68.44 | 92.34 | **+23.90** |
| 研究维度覆盖率 | 91.67% | 100.00% | **+8.33pp** |
| 关键事实覆盖率 | 56.25% | 78.12% | **+21.87pp** |
| 证据不足披露率（14题） | 28.57% | 100.00% | **+71.43pp** |
| 声明证据支持率 | 0.00% | 75.00% | +75.00pp |
| 引用准确率 | 0.00% | 100.00% | +100.00pp |
| 证据可追溯率 | 0.00% | 100.00% | +100.00pp |
| 综合证据质量分 | 35.11 | 90.47 | +55.36 |
| 严格全指标通过率 | 0.00% | 62.50% | +62.50pp |
| 禁止断言命中 | 0 | 0 | 无变化 |
| 最终 Provider Failure | 0 | 0 | 无变化 |

“严格全指标通过”要求所有维度、所有关键事实就近 Evidence 引用、引用准确和不足披露同时满足。它适合做回归门槛，不等同于用户满意度。

## 5. 分类型内容质量

| 类别 | Baseline | PaperAgent | 提升 |
|---|---:|---:|---:|
| 方法比较 | 76.25 | 91.25 | +15.00 |
| 单篇总结 | 73.12 | 100.00 | +26.88 |
| 多论文综合 | 66.88 | 95.62 | +28.74 |
| 证据不足 | 57.50 | 82.50 | +25.00 |

最大收益出现在多论文综合、单篇结构化总结和证据不足处理；方法比较的 Baseline 已能覆盖较多表面维度，PaperAgent 的主要附加价值是证据绑定和边界披露。

## 6. 成本与延迟

| 指标 | Baseline | PaperAgent | 变化 |
|---|---:|---:|---:|
| 总 Token | 18,738 | 69,702 | +50,964 |
| 平均 Token/题 | 1,171.12 | 4,356.38 | **+271.98%** |
| 平均延迟 | 12.219s | 25.342s | +13.123s |
| P95 延迟 | 40.253s | 59.610s | **+48.09%** |
| 最终有效模型调用 | 16 | 16 | 无额外 Reflection；另有 1 次失败请求被定向替换 |

PaperAgent Token 增幅主要来自更长的研究结构、Evidence Store、证据索引和同次 Memory Metadata，而不是额外多次调用。本轮没有触发第二次 Reflection。

## 7. 工程结论

1. Research Writer 明显提高回答完整性、关键事实覆盖和证据不足披露。
2. Evidence ID 约束使最终引用准确率和可追溯率达到 100%。
3. 声明证据支持率为 75%，说明仍有 25% 的人工关键事实没有在同一句中绑定允许证据；这是下一轮最明确的质量缺口。
4. 质量收益伴随显著 Token 和延迟成本，因此完整链路只适用于 L3 研究任务；L1 简单问答继续使用轻量路径。
5. 当前结果来自 16 题小型冻结集，适合简历项目的能力证明，不应表述为生产用户准确率或全领域泛化结论。

## 8. 简历可使用的严谨表述

> 在 16 题真实模型 A/B 中，相比“检索材料后直接生成”，PaperAgent 将不含引用因素的回答内容质量分由 68.44 提升至 92.34，研究维度覆盖率由 91.67% 提升至 100%，证据不足披露率由 28.57% 提升至 100%；同时实现 100% 引用准确率和证据可追溯率。完整研究链路平均 Token 增加 271.98%，因此仅路由至 L3 复杂研究任务。
